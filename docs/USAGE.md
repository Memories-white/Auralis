# 使用指南

[← 返回首页](../README.md) · [下载安装](https://github.com/Memories-white/Auralis/releases/latest) · [问题反馈](https://github.com/Memories-white/Auralis/issues)

## 外观自定义（0.4.4-preview 源码）

0.4.5-preview 起，封面在列表、歌曲栏与播放页共用缓存。已访问图片可在切页时复用；关闭重开会先恢复上次目录内容，再后台刷新。首次升级需要至少成功加载一次目录和图片，才有对应缓存。目录按账号隔离，退出登录清除目录，公开图片继续受磁盘空间上限管理。新的推荐图片和被系统清理的缓存仍需要网络。

进入底部「设置 → 主题与界面」，选择底栏样式、紧凑歌曲栏、界面模糊、导航文字、播放背景、封面形状和列表显示。紧凑模式开启后，播放时歌曲栏也保持收起；进度与播放控制继续可用。动态流光与切歌封面翻转由 Rust 驱动，暂停时背景停留在当前位置。

「设置 → 歌词外观」可调整对齐、字号、字重、渐变模糊、翻译、当前句放大和播放控件。隐藏歌词播放控件后仍保留底部进度条，可返回封面页操作播放。翻译仅显示曲目已有内容。

所有选择自动保存。原有「外观」设置系统/浅/深模式；莫奈选项保留壁纸、封面、自选色、调色板与规范。选择「减少动态效果」可关闭自定义动效，系统关闭动画时始终遵循系统设置。

## 登录与账号信息

打开首页右上角的账号入口，使用服务方客户端扫描二维码并确认登录。登录后入口显示头像，点击进入「音乐库」，可以查看账号信息、喜欢、自建与收藏歌单。歌单支持全部 / 我创建的 / 我收藏的分类。推荐、喜欢列表与歌单需要网络连接。

扫码确认后遇到临时域名解析错误时，应用会自动重试当前授权请求。如果二维码窗口仍提示无法解析某个域名，检查手机当前网络后，点「重新获取」再扫码。

退出入口位于底部「设置」最下方。退出后本地收藏与本机最近播放仍保留。登录凭据使用 Android Keystore AES-GCM 加密存储；不要将应用私有目录、登录二维码、Cookie 或 token 发到 Issue。

### 最近播放（0.3.8-preview）

「音乐库」提供喜欢、本地收藏、最近播放与睡眠定时四个入口。最近播放只在音频成功开始后记录；加载失败、暂停 / 恢复或同一播放请求的音质重载不会产生重复记录。重新播放同一首歌曲会将它移到最前面，最多保留 100 首。

记录仅存于本机，包含歌曲名、歌手、封面地址等歌曲元数据，不保存音源地址或登录凭据；应用退出账号后仍保留，可在「最近播放 → 清空播放记录」中确认删除。点击历史歌曲仍需重新获取当前账号有权使用的播放地址。

## 发现与搜索

首页精选卡提供唯一的每日 30 首入口，点击打开推荐列表，再选择播放全部或随机播放。本地收藏在音乐库中，播放队列可以从歌曲栏或完整播放器打开。

首页按音乐服务返回的类型显示推荐歌曲和歌单。推荐歌曲会排除每日歌曲并去重，可向下滑动或点「加载更多歌曲」继续浏览。后续请求失败时，已显示的歌曲仍可播放，可点「重试」继续加载。滚动一定距离后出现返回顶部按钮。歌单页还可定位当前播放的歌曲。

打开歌单或「喜欢」后，应用会按页读取服务端歌曲。超过 100 首时，向下滚动或点「加载更多歌曲」查看后续曲目。播放全部和随机播放都使用完整列表。

搜索入口在顶部头像附近。搜索页包含推荐歌手、推荐歌曲和最近搜索；点击歌手或历史关键词可直接搜索，点击歌曲立即播放。历史最多保留 8 条，可通过「清空」删除。进入页面不会主动请求输入焦点。

没有推荐数据时先检查登录状态，或点击刷新；不会用虚构的热搜数据填充页面。

0.3.9-preview 起，“猜你喜欢”按专属推荐类型获取歌曲，不再用普通歌单编号查询。打开后可查看实际返回数量、封面和曲目，使用播放全部或随机播放。推荐数量由服务返回及去重结果决定。

## 播放器与进度

0.5.3-preview 起，支持真实逐字时间的曲目会在当前句内随演唱逐词渐亮，未唱部分保持灰色。暂停时停在当前词进度，拖动后重新定位；只有行级歌词的歌曲仍整句高亮，不估算每个词的时间。升级后重新播放曲目，才能通过新接口获取逐字数据。

点击底部歌曲信息打开完整播放器。封面左滑进入歌词，右滑进入歌曲详情。在歌词页右滑或歌曲详情页左滑可回到封面。返回键或顶部收起按钮关闭完整播放器。

0.3.9-preview 起，关闭并重开应用会恢复最后歌曲的封面、歌名、歌手、队列位置和进度。进程已结束时保持暂停，点击播放后重新获取当前账号有权使用的音源并续播；后台服务仍在运行时显示实际会话。

播放中约每 5 秒保存一次，暂停、完成拖动及正常停止时立即保存。队列最多保留当前歌曲附近 500 首，记录仅含歌曲元数据和进度。强制终止可能丢失最近几秒；旧版没有保存的历史进度无法补回，首次升级会用最近成功播放的曲目从 0 开始。

从封面页向右滑可查看歌名、歌手、专辑和时长，实际音质在封面页底部显示。点击封面打开约半屏的功能面板，选择音质、添加到云端我的喜欢，或添加到自建歌单。面板子页可以滚动，通过左上角返回回到面板首页。

添加到自建歌单时，在同一个半屏面板选择目标并查看结果。请求处理期间会暂时禁用歌单选项。应用确认歌曲已在目标歌单后会显示确认，服务仅返回受理时会提示刷新以核对结果。

开始播放后，底部歌曲栏暂时展开，显示进度、时间与控制区；约 4.5 秒后自动收起。进度轨道随展开和收起移动，收起后仍然可见。展开状态可拖动进度，拖动期间保持展开。

播放页左下角图标依次切换顺序、列表循环、单曲循环、随机播放。顺序播放在队列末尾停止；随机使用遍历袋减少重复，上一首按实际播放历史返回。

### 睡眠定时（0.3.8-preview）

播放歌曲后，点击封面页底部的时钟，或从「音乐库 → 睡眠定时」、设置、封面功能面板进入。可以选择 15、30、60、90 分钟后暂停，或当前歌曲播完后暂停。定时期间仍可切页与暂停，倒计时持续计算；选择「关闭定时」取消。

“歌曲播完后暂停”优先于列表 / 单曲循环和自动下一首；手动切歌后跟随新歌曲。到时只暂停，不删除队列。重新点击播放可继续收听。

定时由正在运行的播放服务维护，退出播放页面后继续；停止播放服务、结束进程或重启设备后取消。此功能没有请求精确闹钟权限，不承诺所有系统深度休眠状态下的唤醒精度。

## 音质

点击完整播放页的音质按钮，或进入「设置 → 播放 → 音质」。

| 模式 | 行为 |
| :-- | :-- |
| 自动 | 按 SQ、HQ、标准选择可用音源 |
| SQ 无损 | 优先 FLAC，取决于曲目和账号权益 |
| HQ 高品质 | 优先对应高品质 MP3 |
| 标准 | 请求标准 MP3 |

手动选择 SQ 或 HQ 时，可设置「允许自动降级」。关闭后无法获得该档位就会报告失败，不会静默切换到其他音质。页面显示的是接口实际返回的档位，降级时附带提示。

切换当前歌曲音质会保留进度及播放 / 暂停状态，失败则保留已有音源。下一首沿用保存的偏好。

## 歌词与外观

歌词页当前句清晰放大，前后句按距离渐进模糊，切句时逐行弹性移动。点击某句可以跳到对应时间；手动浏览结束约 1.8 秒后恢复播放位置跟随。底部边框进度条也可跳转。

设置支持跟随系统、浅色与深色。打开「使用莫奈取色」后，可在配色选项选择系统壁纸、封面或自定义颜色，以及色板和颜色规范。系统壁纸动态配色需要 Android 12+，旧系统可使用封面或自定义色源。

## 系统歌词

需要兼容消费端，以及包含 **Auralis 独立适配**的 [LyriconProvider](https://github.com/limczhh/LyriconProvider)。适配路由为 `dev.qqlyric.app → Auralis`；如果安装的版本没有该路由，仅更改包名作用域不会自动实现支持。

按 Provider 与消费端文档启用模块及必要作用域，消费端选择相应 Lyricon 来源。Auralis 通过 Framework MediaSession 发布真实 song mid、歌词与翻译。Provider 安装包不在本仓库附带，避免把独立项目的签名、发布状态与本应用混在一起。

已验证环境中的原文、翻译、暂停、拖动重同步和切歌结果见 [联调记录](../design/LYRICON_VALIDATION.md)。不同系统或消费端可能有不同策略。源数据目前为逐行 LRC，应用动画不等于逐字歌词时间轴。

## 常见问题

| 问题 | 检查方向 |
| :-- | :-- |
| 域名解析失败 | 检查当前网络、系统 DNS 和代理；这是网络连接失败，不等同于登录密码错误 |
| 登录过期 | 重新扫码；当前未实现凭据自动续期 |
| 无播放地址 / 音质不可用 | 检查账号权益、曲目授权、登录状态与是否关闭降级 |
| 歌单只显示前一部分歌曲 | 向下滑到底部或点击「加载更多歌曲」；读取失败时可点「重试」 |
| 后台通知不可用 | 检查通知授权及系统对应用后台运行的限制 |
| 系统歌词不显示 | 检查适配版 Provider、作用域和消费端来源；应用内歌词与系统接收链路是不同环节 |
| 新 APK 无法覆盖 | 核对包名和签名，先备份并确认方案，避免直接卸载丢失数据 |

反馈时提供版本、Android / ROM、复现步骤和已隐藏个人信息的截图。不要附带账号凭据、带授权参数的音源地址或应用私有数据。

# Auralis 0.3.4

> 本项目仅供学习、技术研究与代码参考。请在合法授权范围内使用，遵守第三方服务条款与内容权益；项目代码许可不授予第三方内容使用权。

Rust + Jetpack Compose + MIUIX 的 Android 音乐播放器。本次为开发签名构建，支持 **Android 8.0+ / arm64-v8a**。

## 本次更新

- **发现首页**：参考 Melodist 的布局层次，重新组织快捷入口、每日 30 首、推荐歌曲与歌单。
- **搜索推荐**：增加推荐歌手、推荐歌曲和最近 8 条搜索历史，修正搜索图标留白。
- **连续歌曲栏**：展开与收起共用一条进度轨道，随布局连续移动；封面、时间和控制区重新排布。
- **底栏修复**：二级页面正确避开系统手势区，底栏不再透出下方列表文字。

## 已包含功能

客户端扫码登录、喜欢与歌单、播放队列、后台媒体通知、SQ / HQ / 标准音质、播放顺序切换、渐进模糊与弹性同步歌词、明暗模式和莫奈取色。

歌曲播放与音质受实际账号和曲目授权限制。系统歌词需要带 Auralis 路由的适配版 LyriconProvider 及兼容消费端，安装包不在本 Release 附带。

## 验证

Redmi K60 实机检查：首页和搜索的明暗显示、推荐搜索、播放、歌曲栏展开收起录屏、拖动进度和完整播放器打开返回。拖动并暂停后 MediaSession 位置为 87.837 秒；未做平板或全 ROM 覆盖测试。

Android 离线构建、16 KB zipalign、Rust 11 项单元测试与播放顺序 / 图片缓存 / 封面取色 Java 检查通过。详细记录见仓库 `design/DEVICE_VALIDATION.md`。

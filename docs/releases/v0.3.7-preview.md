# Auralis 0.3.7-preview · 音乐内容层次调整

> 仅供学习、技术研究与代码参考，请遵守授权边界及第三方服务条款。

本版为 UI 预览，尚未完成实机视觉和交互验证。

- 首页先呈现每日精选，快捷入口移到精选卡下方，以两列紧凑入口呈现。
- 精选卡采用大封面和独立播放按钮，拉开标题、说明与操作的层次。
- 推荐封面从卡片内缩略图改为完整图像书架，标题保留两行，减少长名称截断。
- 歌曲列表去掉每行厚重底板，保留当前播放行的选中底色与播放标识。
- 内容分节使用清晰的标题字阶，减少大片灰色分组标签带来的设置页观感。
- 紧凑歌曲栏缩至 72dp，沿用单一进度轨道的展开动画，播放按钮使用主题主色。
- 保留 MIUIX 0.9.5-beta01、莫奈取色、明暗语义色和已有推荐 / 播放功能。

当前检查以构建、资源与代码检查为准。设备未连接，暂不承诺不同字体大小、横屏和全部桌面环境的实际显示效果。历史截图不代表本预览版实机效果。

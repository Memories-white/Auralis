# Auralis 0.3.5

## 个性化发现

- 移除首页顶部重复的每日 30 首快捷入口。
- 推荐歌曲改用 QQ 个性化歌曲货架，排除每日歌单与已展示歌曲，支持下滑分页加载。
- 首页与歌单增加返回顶部；歌单支持定位当前播放曲目。

## 歌曲操作

- 点击封面打开约半屏的歌曲选项，包含音质、添加到 QQ 我的喜欢、添加到自建歌单。
- 同一面板内部切换音质与歌单子页，长内容可以滚动；切歌关闭旧歌曲面板。
- 封面右滑进入歌曲信息，查看歌名、歌手、专辑、时长和实际音质；左滑仍进入歌词。

## 验证与限制

Rust 14 项测试、3 组 Java 检查、完整 Rust / Android 构建及 16 KB zipalign 通过。Redmi K60 实测连续推荐从 36 首增长到 84 首，与每日歌单重合数为 0；验证了返回顶部、歌单定位、半屏菜单及右滑信息页。

云端添加以已有歌单中的现有曲目进行幂等验证并回读成员，未向账号新增任意收藏。服务只有受理而无法回读确认时提示刷新，不显示虚假成功。喜欢和单个歌单当前最多读取前 100 首；新增收藏的数据变化未在本次实测。

仍需真实 QQ 音乐账号与曲目权益；不绕过授权限制。当前构建为开发签名，支持 Android 8.0+ / arm64-v8a。
